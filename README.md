# RouteWise

Deadline-aware comparison of **flights** and **trains**. Not a booking engine.

## Stack

Next.js, TypeScript, Tailwind CSS. API routes on the Next.js server. Supabase and live providers later.

## Setup

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
